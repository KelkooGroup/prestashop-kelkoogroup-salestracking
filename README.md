# Kelkoo Group Sales Tracking - PrestaShop module

Official Kelkoo Group Sales Tracking (KST) module for PrestaShop 1.7, 8 and 9.

Replaces the manual installation procedure (editing `head.tpl`,
`OrderConfirmationController.php` and `order-confirmation-table.tpl` directly
in the merchant's theme) described at
https://docs.kelkoogroup.com/for-advertisers/kelkoo-sales-tracking/installation-methods/installation-guides-for-ecommerce-platforms/prestashop
with an installable module, modeled on the
[WooCommerce KST plugin](https://github.com/KelkooGroup/woocommerce-kelkoogroup-salestracking).

## Installation

Upload the module zip in **Modules > Module Manager > Upload a module**.
The module then appears in **Modules > Advertising & Marketing** as
**Kelkoo Group Sales Tracking**; click **Configure** to enter your
merchant identifier. The full guide is in [PUBLIC-DOC.md](PUBLIC-DOC.md).

## Consent

PrestaShop has no core consent API, so the module can't gate the lead tag
itself (`leadtag.js` reports the IAB TCF consent string when a TCF CMP is
present, but doesn't wait for consent). The settings page tells merchants
what the public KST documentation requires: block the lead tag
(`leadtag.js`) until consent in their CMP, never the conversion tag
(`ks.js`) - so never the whole `s.kk-resources.com` domain either.

## Module layout

```
kelkoogroupsalestracking/
  kelkoogroupsalestracking.php   # main module class (hooks, install/uninstall, getContent)
  logo.png                       # module icon, shown in Modules > Advertising & Marketing
  views/templates/admin/         # settings page template
  views/templates/hook/          # front-office hook templates (lead tag, conversion tag)
  translations/
```

Every folder has an `index.php` that stops it being listed (an Addons
validation rule).

`config.xml` is generated by PrestaShop on install and is not committed (see
`.gitignore`).
